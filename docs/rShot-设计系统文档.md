## 1. 设计原则（继承自指导文档）

克制 · 专业 · 轻量。延续 macOS HIG，对标 iShot Pro / CleanShot X 的克制路线。

- 单一强调色（青蓝系），只用于主操作与激活态
- 毛玻璃材质（vibrancy），不堆 3D 阴影
- 线性图标，统一 1.5pt 描边
- 跟随系统深浅色，**双主题并排展示**（rShot 原型约定）
- 编辑器是核心：必须画出“标注中的真实状态”，不要空界面

红线见第 7 节。

## 2. 设计 Token

### 2.1 主题作用域

原型用两个根 class 承载主题，所有 token 以 CSS 变量定义在作用域内：
- `.theme-light` — 浅色
- `.theme-dark` — 深色

每个屏幕（stage）成对出现：浅色舞台 + 深色舞台，上下并排。

### 2.3 标注调色板（PALETTE）

标注颜色固定 8 色，全工具共用：

```
#FF3B30  #FF9500  #FFCC00  #34C759  #007AFF  #5856D6  #1d1d1f  #ffffff
 红       橙       黄       绿       蓝       紫       黑       白
```

- 文字色 / 数字标记色额外支持 `auto`（浅色模式文字跟随 `--fg`，数字标记跟随 `--accent`）
- 白色色块在浅色模式加 `1px rgba(0,0,0,.15)` 描边以免消失

### 2.4 字体

| 用途 | 字号 | 字重 | 栈 |
|---|---|---|---|
| 正文 | 13pt | 400 / 500 | `-apple-system, "SF Pro Text", system-ui` |
| 标题 | 15–17pt | 600 | `"SF Pro Display"` |
| 数字 / 坐标 / 代码 | 10–11px | 600 | `ui-monospace, "SF Mono", Menlo` |

### 2.5 圆角 / 间距 / 材质

## 3. 组件库

> 组件 class 定义在各 `screen-*.html` 的 `<style>` 内。以下为规范，数值以实现为准。

### 3.1 编辑器浮岛 `.island`（底部工具栏 + 候选条，输入法候选词式）

**用途**：标注工具栏 + 候选条的**统一容器**，位于截图区域外、画布下方正中（可拖动避遮挡）。

- 定位：`position:absolute; top:100%; left:50%; transform:translateX(-50%); margin-top:16px` —— 贴画布底边外、居中、向下，永不遮挡画布
- 结构（从上到下）：`.props`（候选条，选工具后紧贴工具栏**上方**展开）+ `.island-tools`（工具栏，常驻）
- 候选条形态：横向单行（颜色圆点 · 线宽段 · 填充），输入法候选词式；`display:none` 默认隐藏，选工具后 `.show` 展开
- 视觉：磨砂浮岛 + 顶部内高光 + 13px 圆角 + `overflow:hidden`
- 分隔：候选条显示时与工具栏连为一体，一条发丝线区隔（紧贴工具栏正上方，**不是两个胶囊**）
- 可拖动：浮岛顶部小拖柄，单次截图内可整体移动避开要标注的信息

> ⚠️ **设计决定（2026-06-15 定稿）**：编辑器工具栏采用「底部工具栏 + 候选条紧贴上方展开」范式（参考 iShot），取代早前的「顶部一体化浮岛」。亲密性靠「候选条紧贴工具栏正上方、同容器」实现；位置下移到截图区域外，解决了顶部浮岛遮挡画布的问题。每工具单独记忆上次设置，选工具后候选条自动展开。详见记忆文档决策日志 #6。

### 3.2 工具按钮 `.tbtn`

- 尺寸 38×38，圆角 8px，透明底
- 默认 `opacity:.82`；hover 出 9% 前景色底；激活态 `.on` 用 `--accent` 填充 + 蓝色光晕投影
- 图标 SVG：19×19，`stroke-width:1.5`，激活时 1.9
- 分隔符 `.tsep`：水平工具栏里是竖线 `1×22px`

### 3.3 候选条 `.props` / `.pg`（输入法候选词式）

- `.props` 候选条，紧贴工具栏**上方**；`display:none` 默认隐藏，选工具后 `.show` 展开 + 与工具栏连为一体（发丝线分隔）
- `.pg[data-for="<tool>"]` 每个工具一组候选，随当前工具切换显示（整条替换）
- 候选形态：横向单行——颜色圆点（`.swatches`）· 线宽 / 字号段（`.seg`）· 填充开关（`.chk`），组间用竖发丝线 `.cb-sep` 分隔
- 出现动画 `propFade .18s`；每工具独立记忆上次设置，切回时高亮 = 上次值

### 3.4 色板 `.swatches` / `.sw`

- 圆点 20×20，hover 放大 1.15，选中 `.on` 用 `--accent` 双层环（`::after` inset -3px）
- `auto` 色用棋盘格底纹表示

### 3.5 分段控件 `.seg`

- 容器 8% 前景色底 + 10px 圆角，按钮等分
- 选中 `.on`：`--window` 底 + 小投影 + 600 字重

### 3.6 底部操作 `.actions` / `.act`

- 画布外右下，毛玻璃浮岛
- `.act.primary`（复制 / 完成）：`--accent` 填充，主操作
- `.act.ghost`（保存 / 取消）：透明底

### 3.7 OCR 浮层 `.ocr-pop`

- 画布右侧滑出，**独立浮岛**（不并入主浮岛，按需弹出）
- 三态：识别中（spinner）/ 完成（文本）/ 失败
- 头部标题 + 关闭，底部「复制原文 / 完成」

### 3.8 反馈 toast `.toast`

- 屏幕底部居中胶囊，`--chip-bg` / `--chip-fg`，2s 自动消失
- 带勾选图标（`--accent` 描边）

### 3.9 坐标 HUD `.hud-stat`

- 画布**右上角内部**小标签（9px inset），mono 字体
- 显示 VIEWPORT / CURSOR，`pointer-events:none`

### 3.10 被截图窗口框架 `.capture`

- 模拟被截取的真实 app 窗口：标题栏（红黄绿灯 + 标题）+ 侧栏 + 主内容
- 作为编辑器画布内的「被标注内容」

## 5. 标注编辑器（界面 3）核心规范

编辑器是整个项目的中心，单独详述。

### 5.1 工具矩阵

| data-tool | 工具 | PRD ID | 优先级 | 属性面板 |
|---|---|---|---|---|
| `rect` | 矩形框选 | A-02 | P0 | 颜色 / 线宽 / 填充 |
| `text` | 文本 | A-03 | P0 | **样式(透明/底框)** / 字号 / 文字色 / 底框色 |
| `num` | 数字标记 | A-04 | P0 | 序号预览 / 颜色 / 重置序号 |
| `arrow` | 箭头 | A-06 | P1 | 颜色 / 线宽 |
| `mosaic` | 马赛克 | A-07 | P1 | （无） |
| `hl` | 高亮笔 | A-08 | P1 | 颜色 |
| `del` | 删除对象 | A-10 | P1 | （动作，无面板） |

动作按钮（`data-act`）：`undo` 撤销、`ocr` 文本识别。

### 5.2 文本工具的双样式（设计重点）

- **Style 切换**：`transparent`（透明，文字直接落在截图上）/ `boxed`（底框，文字带背景矩形）
- **双色选择**：`textColor`（文字色，支持 auto）+ `textBg`（底框色，仅 boxed 时出现）
- 底框色根据明度自动决定文字色（深底白字 / 浅底黑字），保证对比度

### 5.3 工具栏与候选条的亲密性规则（硬约束）

1. 工具栏常驻画布下方正中（截图区域外）；候选条紧贴工具栏**正上方**展开，同一 `.island` 容器
2. 不可拆成两个独立浮岛（胶囊）；候选条出现时只允许**一条发丝分隔线**区隔
3. 选工具后候选条**自动展开**（输入法候选词式），横向单行候选（颜色 / 线宽 / 填充等）
4. 每工具**单独记忆**上次设置；切回某工具，候选条高亮 = 上次值，多数时候无需调整即可落笔
5. 候选条不跟随光标——固定锚点在底部工具栏，肌肉记忆稳

### 5.4 真交互行为（非静态 mock）

- 画布支持：画矩形 / 画箭头 / 涂高亮 / 框马赛克 / 点数字标记 / 点文本（弹出输入框）/ 双击编辑文本 / 删除命中对象
- 撤销栈（快照式，上限 50）
- 候选条实时联动当前工具，颜色 / 线宽 / 样式选择即时反映到下一次绘制
- 复制 / 保存 / 取消均触发 toast 反馈

## 6. 双主题并排约定

rShot 原型**不**做主题切换器，而是把浅 / 深两个舞台上下并排渲染在同一页（`.dock` 容器）。原因：
- 评审时一眼看清两种模式
- 不在产品 UI 里暴露「切换控件」（违反产品真实感）
- 两个舞台共享同一套 JS 逻辑（`$all(...)` 同时作用于浅深）

## 7. 红线（不要做）

- ❌ 拟物化、渐变按钮、3D 阴影堆叠、Windows 风
- ❌ 多个强调色（只有青蓝 `--accent`）
- ❌ 工具栏拆成两个分离胶囊浮岛
- ❌ 候选条跟随光标跳动（应固定锚点在底部工具栏正上方）
- ❌ 编辑器空界面（必须画出标注中状态）
- ❌ 在产品 UI 里暴露主题切换器 / 视口选择器 / 设计元数据
- ❌ 编辑器用静态 mock 代替真交互
