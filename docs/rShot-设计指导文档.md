# rShot 设计指导文档（供 OpenDesign 使用）

> 配套文档：`rShot-产品需求文档.md`（功能与优先级以那份为准）
> 目标：产出 rShot 的视觉与交互原型设计稿
> 平台：macOS 27.0 原生 Mac 应用

---

## 1. 设计目标

为 rShot 设计一套**克制、专业、轻量**的 macOS 原生截图工具界面。整体延续 macOS Human Interface Guidelines，视觉风格对标 iShot Pro / Longshot / CleanShot X 的克制路线，不做拟物、不做花哨装饰。

核心体验关键词：**触发快、框选准、标注顺、保存省事**。

---

## 2. 设计规范约束

| 维度 | 要求 |
|------|------|
| **平台** | macOS 27.0 原生 Mac 应用（非 iOS、非 Web） |
| **配色** | 跟随系统深浅色模式，双主题都要出 |
| **品牌色** | 单一强调色，建议**青蓝（#0A84FF 系）**，仅用于主操作与激活态 |
| **字体** | SF Pro Text / SF Pro Display；正文 13pt，标题 15-17pt |
| **材质** | 工具栏与浮动面板使用毛玻璃（NSVisualEffectView / vibrancy）|
| **图标** | 线性图标，SF Symbols 风格，统一描边粗细（1.5pt）|
| **控件尺寸** | 按钮 24-28pt 高，工具栏图标 16-20pt，符合 macOS 标准 |
| **圆角** | 控件 5-6pt，浮动面板 10pt，窗口 10pt |
| **分辨率** | 提供 @1x 与 @2x，默认 Retina |
| **明确不要** | 拟物化、渐变按钮、过多动效、Windows 风格、3D 阴影堆叠 |

## 3. 需要交付的原型界面（按优先级）

> 以下编号对应 PRD 中的功能 ID。**P0 为必出设计，P1 为建议出**。

### 界面 1：菜单栏常驻 + 下拉菜单（P0，对应 S-04）

- **菜单栏图标**：简洁相机/截图图标（线性），深浅色自适应
- **下拉菜单项**：
  - 区域截图（显示快捷键，如 ⇧⌘A）
  - 全屏截图（如 ⇧⌘S）
  - OCR 截图（如 ⇧⌘O）
  - 分隔线
  - 设置…
  - 退出 rShot
- **状态**：默认态、展开态

### 界面 2：区域截图框选态（P0，对应 S-01）

- 选区外屏幕区域：**半透明黑色遮罩（约 60% 不透明度）**
- 选区内：清晰显示原图
- 选区边框：1pt 品牌色高亮描边
- 选区旁浮层显示：
  - **尺寸标签**：如 `1280 × 720`
  - **坐标**：如 `x: 240, y: 160`（可选，小字）
- 选区可拖拽四角/四边调整
- 框选完成后自动进入「界面 3：标注编辑器」

### 界面 3：标注编辑器（核心，P0，对应 A-01 ~ A-05）

这是**最核心、最需要重点设计**的界面。框选完成后出现。

#### 3.1 整体布局

- 截图保持在原位（或居中放大），周围仍是遮罩
- **悬浮工具栏**：出现在截图旁边（参考 iShot Pro），毛玻璃材质
- **底部操作区**：保存相关按钮

#### 3.2 工具栏（P0 工具，必出）

| 图标位置 | 工具 | ID | 视觉要求 |
|----------|------|----|---------|
| 1 | 矩形框选 | A-02 | 矩形线性图标 |
| 2 | 文本 | A-03 | "T" 字图标 |
| 3 | 数字标记 | A-04 | 圆形带数字图标（①）|
| 4 | 撤销 | A-05 | 左旋箭头 |
| 5 | 重做 | A-05 | 右旋箭头 |
| 6 | OCR | O-01 | 文字识别图标 |

**P1 工具（建议在设计稿中预留位置，可置灰或单列）：**

| 工具 | ID | 视觉要求 |
|------|----|---------|
| 箭头 | A-06 | 斜向箭头 |
| 马赛克/模糊 | A-07 | 像素方块图标 |
| 高亮笔 | A-08 | 荧光笔图标 |
| 删除对象 | A-10 | 橡皮/垃圾桶 |

#### 3.3 属性面板（选中工具后出现）

选中某个标注工具后，工具栏旁/下方展开次级属性：

- **矩形框选**：颜色板（5-8 种预设色）+ 线宽（细/中/粗）+ 填充开关
- **文本**：字号（小/中/大）+ 文字颜色 + 背景色（半透明）开关
- **数字标记**：当前序号 + 气泡颜色

#### 3.4 标注中的状态示意（必须展示）

设计稿中要**画出至少一个正在标注的状态**，建议展示：
- 截图上已有 1 个**矩形框选**（某区域被框住）
- 1 个**数字标记①** 在框旁
- 1 个**文本标注** "问题点"
- 工具栏中「数字标记」处于激活态，属性面板展开

#### 3.5 底部操作区（P0）

| 按钮 | ID | 样式 |
|------|----|------|
| **复制 / 完成** | F-01 | 主按钮（品牌色填充）|
| 保存 | F-02 | 次按钮（描边）|
| 取消（×）| F-03 | 工具栏末端，纯图标 |

> 另存为（F-04，P1）可预留位置。

### 界面 4：OCR 结果面板（P0，对应 O-01、O-02）

- 触发 OCR 后，从截图旁/下方滑出结果面板
- **内容**：识别出的文本，可编辑、可全选复制
- **顶部**：「识别文本」标题 + 复制按钮 + 关闭按钮
- **状态**：识别中（loading）、识别完成（文本）、识别失败（错误提示）

### 界面 5：设置窗口（P0，对应 C-01 ~ C-03）

标准 macOS 设置窗格（NSTabViewController 风格，左侧标签页）：

- **通用**：默认保存路径（路径选择器）、图片格式（PNG/JPG，P1 可先置默认 PNG）、自动复制开关（P1）
- **快捷键**：区域截图、全屏截图、OCR 截图的快捷键录入框
- **OCR**：OCR 语言（中/英/中英，P1）

### 界面 6：截图完成反馈（P0）

- 截图复制/保存成功后，菜单栏图标处出现**轻量 toast / 提示气泡**
- 文案如「已复制到剪贴板」「已保存至 ~/Screenshots」
- 2 秒后自动消失，不打断用户

## 4. 交互流程图（文字版，供设计参考）

```
菜单栏图标 / 快捷键
        │
        ▼
   选择模式（区域 / 全屏 / OCR）
        │
        ▼
[区域] 拖拽框选 ──ESC──> 取消退出
        │
        ▼
   标注编辑器（可加标注 / 可不加）
        │
   ┌────┼────────┬─────────┐
   ▼    ▼        ▼         ▼
 复制  保存    另存为     OCR
(剪贴板)(路径) (P1)    结果面板
   │    │                 │
   └────┴────────┬────────┘
                 ▼
          完成反馈 toast
```

## 5. 视觉参考说明（不要照抄品牌）

| 参考 | 借鉴点 |
|------|--------|
| **iShot Pro** | 悬浮工具栏的紧凑布局；框选 → 工具栏 → 自动复制的交互节奏；序号气泡标注的形态 |
| **Longshot** | 步骤标注（step annotation）的清爽视觉；马赛克/高亮的克制处理 |
| **CleanShot X** | 毛玻璃工具栏质感；框选时尺寸标签的呈现方式 |
| **macOS 原生截图** | 框选遮罩的透明度与边框高亮 |

## 7. 约束提醒（给 OpenDesign 的硬性要求）

1. ✅ 必须是 **macOS 原生**风格，不是 iOS、不是 Web
2. ✅ 必须**跟随系统深浅色**，两套都要
3. ✅ 标注编辑器（界面 3）是重点，要画出**标注中的真实状态**，不要空界面
4. ✅ 用 **SF Pro 字体 + SF Symbols 风格图标 + 毛玻璃材质**
5. ✅ 强调色只用一个（青蓝系），克制
6. ❌ 不要拟物、不要渐变按钮、不要 3D 阴影、不要 Windows 风
