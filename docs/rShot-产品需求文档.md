# rShot 产品需求文档（PRD）

> 版本：v1.0 · 日期：2026-06-15 · 状态：待评审
> 平台：macOS 27.0（原生 Mac 应用）

---

## 1. 产品概述

**rShot** 是一款轻便的 macOS 截图工具，整合「截图 + 标注 + OCR」三大能力。常驻菜单栏，快捷键触发，框选后进入标注编辑器，完成后可复制到剪贴板或保存到固定路径，并支持 OCR 文字识别。

**定位**：克制、专业、轻量。对标 iShot Pro、Longshot，但只聚焦核心高频能力，不做录屏、翻译、取色等扩展。

---

## 2. 优先级定义

| 级别 | 含义 | 交付要求 |
|------|------|----------|
| **P0** | 必须有（MVP）| 第一版必须实现，缺失则产品不成立 |
| **P1** | 应该有 | 建议在第一版或紧随其后的版本实现，显著提升体验 |
| **P2** | 可以有 | 后续迭代，视时间和反馈决定 |

## 3. 功能需求清单

### 3.1 触发与截图

| ID | 功能 | 说明 | 优先级 |
|----|------|------|--------|
| S-01 | 区域截图 | 快捷键触发后，鼠标拖拽框选矩形区域 | **P0** |
| S-02 | 全屏截图 | 快捷键触发，捕获整个屏幕 | **P0** |
| S-03 | 窗口截图 | 自动识别并高亮鼠标下窗口，点击截取 | P1 |
| S-04 | 菜单栏常驻 | 菜单栏图标 + 下拉菜单触发各截图模式 | **P0** |

> ❌ 已排除：延迟截图（用户确认不需要）

### 3.2 截图标注（编辑器）

| ID | 功能 | 说明 | 优先级 |
|----|------|------|--------|
| A-01 | 标注编辑器 | 框选完成后弹出悬浮标注工具栏，进入编辑态 | **P0** |
| A-02 | 矩形框选标注 | 画矩形高亮框；可选填充色 / 边框色 / 线宽 | **P0** |
| A-03 | 文本标注 | 任意位置添加文字；字号可调；可选背景色 | **P0** |
| A-04 | 数字标记 | 圆形序号气泡（①②③…），自动递增，颜色可换 | **P0** |
| A-05 | 撤销 / 重做 | 标准撤销栈 | **P0** |
| A-06 | 箭头 | 起止两点，指向某处 | P1 |
| A-07 | 马赛克 / 模糊 | 涂抹区域隐藏敏感信息 | P1 |
| A-08 | 高亮笔 | 半透明荧光笔效果（默认黄） | P1 |
| A-09 | 画笔 / 自由绘制 | 平滑曲线，线宽可调 | P2 |
| A-10 | 删除标注对象 | 点击对象删除（橡皮） | P1 |

### 3.3 完成与保存

| ID | 功能 | 说明 | 优先级 |
|----|------|------|--------|
| F-01 | 复制到剪贴板 | 主操作按钮；截图默认自动复制 | **P0** |
| F-02 | 保存到固定路径 | 次按钮；路径在设置中配置 | **P0** |
| F-03 | 取消截图 | ESC 或关闭按钮；不保存直接退出 | **P0** |
| F-04 | 另存为… | 触发系统保存对话框 | P1 |

### 3.4 OCR

| ID | 功能 | 说明 | 优先级 |
|----|------|------|--------|
| O-01 | 识别截图内文字 | 对截图/选区执行 OCR，弹出结果面板 | **P0** |
| O-02 | 结果面板 | 显示识别文本，可编辑、可全选复制 | **P0** |
| O-03 | OCR 触发入口 | 标注编辑器内 OCR 按钮 + 菜单栏选项 | **P0** |
| O-04 | OCR 语言切换 | 支持中/英，可在设置配置 | P1 |

### 3.5 设置

| ID | 功能 | 说明 | 优先级 |
|----|------|------|--------|
| C-01 | 设置窗口 | 标准 macOS 设置窗格 | **P0** |
| C-02 | 快捷键配置 | 可自定义各模式快捷键 | **P0** |
| C-03 | 默认保存路径 | 配置固定保存位置 | **P0** |
| C-04 | 图片格式 | PNG / JPG 选择 | P1 |
| C-05 | OCR 语言设置 | 中/英/中英 | P1 |
| C-06 | 自动复制开关 | 截图后是否默认复制到剪贴板 | P1 |

## 4. 非功能需求

| 类别 | 要求 |
|------|------|
| **性能** | 截图触发到框选就绪 < 200ms；OCR 响应 < 3s（视图片大小） |
| **稳定性** | 不阻塞系统，异常退出不丢失已标注内容 |
| **权限** | 需申请「屏幕录制」权限（截屏）与（如用系统 OCR）相关权限 |
| **可访问性** | 遵循 macOS 辅助功能，支持全键盘操作、VoiceOver |
| **兼容性** | macOS 27.0，支持 Intel + Apple Silicon |
| **本地化** | 首版中文界面，预留英文扩展 |

## 5. MVP 范围（第一版交付边界）

**必须完成（P0）：**

- 区域截图（S-01）、全屏截图（S-02）、菜单栏常驻（S-04）
- 完整标注编辑器（A-01）含：矩形框选（A-02）、文本（A-03）、数字标记（A-04）、撤销/重做（A-05）
- 复制到剪贴板（F-01）、保存到固定路径（F-02）、取消截图（F-03）
- OCR 识别 + 结果面板 + 触发入口（O-01、O-02、O-03）
- 设置窗口 + 快捷键配置 + 默认保存路径（C-01、C-02、C-03）

**不在 MVP（后续迭代）：**

- 窗口截图、箭头、马赛克、高亮笔、自由画笔、删除工具、另存为、OCR 语言切换、格式选择、自动复制开关
- 长截图、贴图、录屏、翻译、取色（明确不做）

## 6. 竞品参考

| 竞品 | 可借鉴 | 不借鉴 |
|------|--------|--------|
| **iShot Pro** | 框选 → 悬浮工具栏 → 自动复制的交互流；序号气泡标注的形态 | 录屏、翻译、取色、贴图等过宽能力 |
| **Longshot** | 序号步骤标注（step annotation）、马赛克、高亮的视觉处理 | 滚动长截图（非 rShot 定位） |

**共同验证过的高频模式（rShot 延续）：**
1. 快捷键触发 → 框选 → 悬浮工具栏 → 自动复制
2. 序号气泡用于分步说明，是高频标注
3. 马赛克 + 高亮是标注标配（P1）
