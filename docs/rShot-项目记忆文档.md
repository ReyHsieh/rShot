## 4. 关键设计决策日志

### #1 双主题并排展示（不设切换器）
浅 / 深两个舞台上下并排，共享 JS。不在产品 UI 暴露主题切换。→ 评审一眼看清两模式。

### #2 编辑器必须真交互（非静态 mock）
画布支持真画矩形 / 箭头 / 高亮 / 马赛克、点数字 / 文本、双击编辑、删除、撤销栈。属性面板实时联动。→ 满足 PRD「编辑器是核心」。

### #3 编辑器浮岛一体化（2026-06-15，⚠️ 已被 #6 取代）
**背景**：浮岛经历过 3 个形态——
1. 早期：上下两条分离胶囊（工具栏 + 属性面板各自独立浮岛）
2. 中期：侧边垂直浮岛（工具栏左竖排 + 属性面板右侧独立）
3. **当前：一体化顶部浮岛**（工具栏水平在上 + 属性面板紧贴其下、同一容器，一条发丝线区隔）

**决策依据**：
- 设计感：不想要「两条胶囊」的分离感
- 亲密性（格式塔）：选完工具紧接着选属性，二者必须视觉贴近——同容器 + 垂直紧邻，认知距离最小
- 二者合一是「统一一条主工具条 + 更精致视觉」目标的正确落地

**硬约束**：浮岛必须是单一 `.island` 容器；属性面板出现时只允许一条分隔线，不可拆成两个浮岛。详见设计系统文档 §3.1、§5.3。

### #4 文本工具双样式 + 双色
透明 / 底框 切换；文字色 + 底框色双选（底框色据明度自动配文字色保对比度）。

### #5 设计指导文档优先级最高
当加载的默认 / 付费设计系统（如 Premium：暖米色 + Canela 衬线）与指导文档冲突，**以指导文档（macOS 原生 spec）为准**。

### #6 编辑器工具栏：底部工具栏 + 候选条紧贴上方（2026-06-15，最新，取代 #3）
**决定**：编辑器工具栏从「顶部一体化浮岛」改为「**底部工具栏 + 候选条紧贴工具栏正上方展开**」（输入法候选词式，参考 iShot）。

**形态**：
- 工具栏常驻画布**下方正中**（截图区域外，可拖动避遮挡）
- 选工具后，候选条紧贴工具栏**正上方**展开、连为一体（同容器 + 发丝线分隔）
- 候选条横向单行（颜色 · 线宽 · 填充 等），输入法候选词式
- 每工具**单独记忆**上次设置；选工具后**自动展开**

**取代 #3 的理由**：
- #3 顶部浮岛会遮挡画布顶部；下移到截图区域外彻底解决
- 「候选条紧贴工具栏」比「属性面板跟随光标」更稳（固定锚点，肌肉记忆强）
- 仍保持「工具→属性同容器亲密」，只是位置和展开方向变了

**硬约束**：候选条不跟随光标，锚定底部工具栏；不可拆成两个胶囊。详见设计系统文档 §3.1、§5.3。探索稿见 `editor-exploration-ime-2.html`（已冻结，不再改）。
